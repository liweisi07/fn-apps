# 可乐的应用源

飞牛 fnOS 第三方应用源，收录可乐阅读与 CF 优选 IP（域名版）。

## 怎么添加

1. 打开飞牛应用中心。
2. 进入 **设置 → 外部应用源 → 添加**。
3. 填入本仓库地址：

```
https://github.com/liweisi07/fn-apps
```

4. 保存后，在应用中心里就能找到下面 2 个应用，一键安装、更新。

也可以直接下载各应用目录下的 `.fpk`，在应用中心用「手动安装」上传安装。

## 应用列表

| 应用 | 版本 | 端口 | 简介 |
|---|---|---|---|
| 可乐阅读 | 1.0.3 | 18090 | 私有云书架：把 NAS 上的 PDF、EPUB、TXT、AZW3 电子书和漫画集中管理，手机和电脑用浏览器在局域网内打开就能看，阅读进度自动同步到本机，不设文件大小限制。 |
| CF优选IP（域名版） | 1.0.16 | 18089 | 定时测出最优 Cloudflare IP，自动把自定义域名的 DNS 记录（仅 DNS 解析，不开代理）指向最优 IP；订阅里走 CF 的节点地址写成该域名，客户端更新订阅或等 DNS 生效即拿到优选 IP。 |

## 说明

- 2 个应用均为 ARM64 原生 `.fpk` 包（飞牛 RK3566 等 ARM 设备可用），由官方 `fnpack` 工具打包。
- 可乐阅读装机前需先在飞牛应用中心安装 Python 工具；书库文件夹须在飞牛文件管理里给 `kele` 账号读权限。
- 域名版的域名 DNS 须托管在 Cloudflare。
- 设置页与订阅链接只在局域网内用，不映射公网、不外发；订阅与令牌配置只存在本机。
- 从 1.0.2 升 1.0.3 是普通升级：内部名都是 kele，直接在应用中心更新或手动安装覆盖即可，书库、进度、封面都保留。
- 从 1.0.1（满月阅读）升级须先卸载旧版（内部名 manyue），再装新版（内部名 kele），装好重设书库文件夹并重新扫描，旧阅读进度与封面不带过来。
